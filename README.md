# KeepPushing

KeepPushing is a browser-based 3D racing game built with Three.js and Cannon-es.  
Players can control a race car to navigate a procedurally generated track, avoid obstacles, and enjoy a forest environment with randomized trees.

## Features

- 🏎️ Player-controlled car using keyboard input.
- 🌿 Slows down when driving off-road onto grass.
- 🧱 Randomly generated obstacles on the track.
- 🛣️ Randomized track layout on every load.
- 🌲 Randomized trees outside the track to simulate a forest.
- 🎯 Objective: Reach the goal as fast as possible while avoiding obstacles.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/KeepPushing.git
   cd KeepPushing
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Open your browser and go to `http://localhost:5173/` to start the game.

## Controls

- W / ↑ : Accelerate
- S / ↓ : Brake / Reverse
- A / ← : Turn Left
- D / → : Turn Right
- Space : Handbrake

Enjoy racing and try to stay on the track!
